# Vesta Nest website

Public information and privacy policy for the Vesta Nest reader and the Nest integration in Vesta Home. Home controls are distinct from the standalone reader’s read-only behavior. This directory is the source copy; deployment to the separate Pages repository is a separate step.

This repository contains only static website files. It contains no OAuth
credentials, private configuration, thermostat readings, or application history.

GitHub Pages publishes the root of the `main` branch. No build, dependencies,
JavaScript, or external fonts are required.

- Homepage: https://ahwkuepper.github.io/vesta-nest-site/
- Privacy: https://ahwkuepper.github.io/vesta-nest-site/privacy.html

To update, edit the HTML/CSS, check the links, and push the changes to `main`.
Google Search Console verification HTML files or meta tags may be added here if
Google requests proof of ownership. Never add authorization codes or credentials.

For your own OAuth branding, adapt these pages with your contact details and a domain you control. Do not claim ownership of the maintainer’s domain. A public Home setup link should be checked after the source snapshot is promoted.
